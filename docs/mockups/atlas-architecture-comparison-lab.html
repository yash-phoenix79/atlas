Design decision · phase 04
Same library. Different mental models.

What should Atlas feel like when you think?

Three distinct product architectures for the same core job: capture knowledge, recover it from partial memory, connect sources, and turn evidence into something reusable. Choose a direction to inspect its interaction model. This is a comparison prototype, not an approved design.

Fair comparison rule: each direction uses the same six sample resources and the same user jobs. The architecture changes; the underlying resource identity does not.
Task A · Retrieval

Find the half-remembered idea

“I saved something about finding information without remembering its exact title.”

Task B · Synthesis

Connect three useful sources

Build a model from a user problem, a retrieval principle, and a trustworthy source.

What to evaluate
Time-to-find, wrong turns, source confidence, ability to recover, keyboard-only completion, mobile behavior, and whether users understand where their canonical resources live. Visual preference alone is not enough to select the architecture.
Illustrative sample content only. No real semantic search, persistence, integrations or AI. No browser automation, user study, accessibility audit or production readiness is claimed by this artifact.
