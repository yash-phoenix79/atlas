Proposed sequence for a research synthesis. This diagram puts source retrieval and provenance checking on the main path; no provider, model, or real orchestration is claimed to exist.

Source locator

Every material claim must point to a retained resource and a passage/locator that can be opened.

Verification state

Represent cited, locator-resolved, unsupported, conflicting, and reviewer-confirmed distinctly.

User agency

The user can inspect, correct, reject, and export. No generated output is labeled verified merely because a model returned it.
