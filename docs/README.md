# Atlas Documentation

The project is in discovery. Add documents as findings and decisions become concrete.

- `product-vision.md`: intended users, problems, product principles, and desired outcomes.
- `product-feature-blueprint.md`: proposed feature map, initial prioritization hypothesis, screen inventory, and mandatory pre-code mockup approval gate.
- `research/`: sourced research, app teardowns, experiments, and observations. See `research/ui-ux-research-plan.md` for the UI/UX principles, agent-ready UI skill/tool evaluation, and mockup plan.
- `competitive-analysis.md`: cross-product comparison with sources and confidence.
- `requirements.md`: MVP scope and observable acceptance criteria.
- `architecture.md`: proposed design, alternatives, trade-offs, and risks.
- `decisions/`: short, dated decision records.

Avoid duplicating the same information across multiple documents. Link to the canonical note instead.
