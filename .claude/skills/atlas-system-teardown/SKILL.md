# Atlas System Teardown

1. Read AGENTS.md and docs/research/multi-agent-first-principles-protocol.md.
2. State the specific Atlas decision this research could change.
3. Identify the canonical repository/docs, license, release/commit and access date.
4. Trace at least one successful journey and one failure/import/export journey.
5. Inspect seven layers: product behavior; domain/data model; ingestion/background work; API/auth; search/AI/provenance; backup/export/sync; deployment/tests/security/license.
6. Prefer source code, official docs, tests, schema, release notes and reproducible observations. Landing pages are not implementation evidence.
7. Label each material claim Observed, Verified, Primary-source claim, Secondary-source claim, Inference, Hypothesis or Unknown.
8. Record exact paths/links, caveats, counterevidence and inaccessible areas.
9. Finish with Atlas implications, anti-patterns, unknowns and experiments.
10. Do not copy code wholesale or bypass controls; review licenses before any reuse.
